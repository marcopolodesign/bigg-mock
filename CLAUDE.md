## Project Overview

BIGG Mock — A React + Vite + Tailwind CSS v4 web prototype for the BIGG fitness app. Imports are generated by Figma Make; this project is the integration layer where generated screens get wired up, refined, and extended.

## Stack

| Layer | Tool |
|-------|------|
| Framework | React 18 + Vite 6 |
| Styling | Tailwind CSS v4 |
| UI primitives | shadcn/ui (Radix UI) |
| Icons | lucide-react |
| Charts | recharts |
| Motion | motion (Framer Motion) |
| Forms | react-hook-form |

## Design Conventions

- **Font — always use CSS font-family strings:** `'MessinaSansWeb:Bold'`, `'MessinaSansWeb:SemiBold'`, `'MessinaSansWeb:Regular'`, `'MessinaSansWeb:Book'`. Also available: `'Druk_Wide'`, `'Fixture_Ultra'`, `'SF_Compact_Display'`. Applied via Tailwind's `font-['...']` escape syntax.
- **Design system:** Always check `design-system.md` for CSS custom property tokens before writing inline styles.
- **Component reference:** Always check `components.md` before creating a new component. Reuse shadcn/ui primitives from `src/app/components/ui/`.
- **Language:** All user-facing copy is in Spanish (Latin American). Keep it natural and fitness-brand appropriate.
- **Layout:** Default to flexbox and grid. Use absolute/fixed positioning only when strictly necessary for overlays or decorative elements.
- **Responsive:** Mobile-first. The primary viewport is ~390px (iPhone), with tablet/desktop as secondary.
- **No arbitrary magic numbers:** Use CSS custom properties or Tailwind scale tokens. If you must use a raw px value, comment why.

## Figma → Code Flow

Screens come in via `src/imports/` (generated by Figma Make). The pattern:
1. Generated component lives in `src/imports/<ScreenName>/<ScreenName>.tsx`
2. App entry in `src/app/App.tsx` imports and renders it
3. Refinements (interactivity, data wiring, component extraction) happen inside `src/app/components/`
4. Never edit files inside `src/imports/` directly — they get regenerated. Extract what you need into `src/app/components/`.
